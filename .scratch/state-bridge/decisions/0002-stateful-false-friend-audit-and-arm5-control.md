# Stateful False-Friend Audit Framing and Equal-Token Unrelated-Slice Negative Control (Arm 5)

Because 88.9% of top-level public functions and 83.3% of `Session`/`Client` methods in `requests 2.34.2` and `httpx 0.28.1` have identical names (`Edit Distance = 0`), we frame `TwinAPI` not as a naive function-name lookup task, but as a quantitative **Stateful False-Friend Audit** demonstrating that high lexical, signature, and 256-d embedding similarity (`>0.85`) masks five classes of cross-function multi-step behavioral divergence. Furthermore, because shuffling external graph edge headers while keeping identical function bodies leaks call edges through inline function call syntax, we define `Arm 5` as an **Equal-Token Unrelated Function Slice** from the same repository, cleanly isolating the causal contribution of true stateful call-graph edges (`Arm 4`) from prompt token length.
