# Dual-Track Frozen Generation Replay with Live Loopback HTTP State-Machine Execution

We execute `Gemma-4-31B-IT` and `Gemma-4-26B-A4B-IT` once during benchmark construction (`temperature=0.0`, `max_tokens=8192`, `<thought>` stripped and accounted separately), freezing all prompts, raw model outputs, and extracted Python code into `artifacts/raw_llm_generations.jsonl`, while the default `reproduce-paper` CLI and Kaggle Notebook (`Run All`) replay those frozen generations live against the deterministic `127.0.0.1:0` `ThreadingHTTPServer` Loopback State Machine in under 15 seconds without requiring API keys or a 60 GB GPU (preserving an opt-in `--live-inference` flag for full regeneration). This resolves the conflict between 100% real dual-model inference and 60-second zero-credential judge verifiability on Kaggle, and avoids Magpie `google` provider-wide 429 cooldown contagion during evaluation.
